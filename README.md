# Flexbox to Responsive Nav Lab

A hands-on repository dedicated to mastering CSS Flexbox fundamentals and building responsive navigation systems from scratch.

## Overview
This project documents progressive coding exercises, layout drills, and responsive navigation patterns built using semantic HTML5 and modern CSS3.

## Core Focus Areas
- **Flexbox Architecture:** Main and cross-axis alignment, flex-grow, flex-shrink, flex-basis, wrapping, and gap spacing.
- **Navigation Patterns:** Horizontal navbars, logo-and-link splits, centered menus, and call-to-action button groupings.
- **Responsive Adaptation:** Mobile-first media queries, layout stacking, and clean hamburger menu transitions.

## Tech Stack
- HTML5
- CSS3 (Native Flexbox & Custom Media Queries)
- Vanilla JavaScript (for interactive mobile menu toggles)
